# Moon-MonoRepo

## Quick Start (Installation & Setup)

This script will automatically download the template, prompt you for the organization/scope, and configure all target files.

### One-line Bootstrap

Run the following command:

```bash
python3 <(curl -sSL https://raw.githubusercontent.com/MauroGonzalez51/moon-monorepo/main/scripts/init-repository.py)
```
